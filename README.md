# 1. Project Title / Headline

**Online Education Analytics Dashboard | Student Performance & Engagement Analysis**

# 2. Short Description / Purpose

An interactive **Online Education Analytics Dashboard** developed to analyze student performance, engagement, online activity, and dropout patterns. The project combines **MySQL/SQL for data analysis** with **Power BI for interactive visualization**, helping transform student data into meaningful insights for understanding learning outcomes and engagement trends.

# 3. Tech Stack

* **MySQL** – Database management and data analysis
* **SQL** – Data querying, aggregation, and analysis
* **Power BI** – Dashboard development and data visualization
* **CSV Dataset** – Source data

# 4. Data Source

The project uses an **Online Education student dataset** containing student-level information related to academic performance, online activity, engagement, dropout status, education background, and region.

Key fields analyzed include:

* Student ID
* Average Score
* Total Clicks
* Pass Status
* Dropout Status
* Engagement Level
* Performance Level
* Highest Education
* Region

The SQL analysis calculates metrics such as total students, average score, average clicks, pass/dropout counts, engagement-level performance, click-band performance, dropout rates, education-level performance, and regional analysis.

# 5. Features / Highlights

## 🔹 Business Problem

Online education platforms generate large amounts of student activity and performance data, making it difficult to identify patterns in **student engagement, academic performance, and dropout behavior** from raw data alone.

The project addresses this problem by organizing and analyzing student data and presenting the results through an interactive dashboard.

## 🔹 Goal of the Dashboard

The main goal is to provide a clear view of:

* Overall student population
* Student performance
* Online learning activity
* Engagement levels
* Pass and dropout patterns
* Performance across different engagement levels
* Performance and activity across education levels
* Regional student and performance trends

## 🔹 Walkthrough of Key Visuals

### KPI Cards

The dashboard provides key metrics such as:

* **Total Students**
* **Average Student Score**
* **Average Total Clicks**
* **Students Passed**
* **Students Dropped Out**

These provide a quick overview of the overall learning population and performance.

### Engagement Analysis

Visuals compare different **engagement levels** based on student count and average score, helping identify how engagement varies with academic performance.

### Click Activity Analysis

Students are grouped into click-activity ranges such as **0–500, 500–1000, 1000–2000, 2000–3000, and 3000+**, with their student count and average score analyzed.

### Dropout Analysis

The dashboard compares dropout counts and dropout rates across **engagement levels and performance levels** to highlight differences in dropout patterns.

### Education Analysis

Visuals compare student count, average score, and average clicks across different **highest education levels**.

### Regional Analysis

Regional visuals show student distribution along with average score and average online activity for different regions.

## 🔹 Impact & Insights

The dashboard converts raw online education data into an easy-to-understand visual format, enabling users to:

* Monitor overall student performance and activity.
* Identify differences in engagement levels.
* Examine the relationship between online activity and performance.
* Compare dropout patterns across engagement and performance groups.
* Understand differences across education levels.
* Analyze student distribution and performance across regions.

Overall, the project demonstrates how **SQL-based analysis and Power BI visualization** can be combined to support data-driven understanding of online learning trends.
